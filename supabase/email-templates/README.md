# Template email Supabase Auth

Pasang di Supabase Dashboard → Authentication → Emails → Templates.

| Template         | Subject                                              | Body                  |
|------------------|------------------------------------------------------|-----------------------|
| Confirm signup   | Konfirmasi email kamu · Jersey Pattern Lab           | confirm-signup.html   |
| Reset password   | Atur ulang password akun Jersey Pattern Lab          | reset-password.html   |

Nama pengirim "Supabase Auth" hanya bisa diganti lewat Custom SMTP
(Authentication → Emails → SMTP Settings), misalnya pakai Resend.
